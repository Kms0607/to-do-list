이 프로젝트는 HTML, CSS, JavaScript를 사용하여 만든 간단한 할 일 관리 웹 페이지이다. 사용자는 할 일을 입력하고, 추가된 항목을 완료 처리하거나 수정, 삭제할 수 있다. 또한 LocalStorage를 사용하여 새로고침 후에도 할 일 목록이 유지되도록 구현하였다.  

#주요 기능 목록  
할 일 추가 기능  
할 일 완료 처리 기능  
할 일 수정 기능  
할 일 삭제 기능  
Enter 키로 할 일 추가 기능  
LocalStorage를 이용한 데이터 저장 기능  
새로고침 후에도 목록 유지 기능  
완료된 항목 취소선 표시 기능  

#적용된 javascript 핵심 기술  
dom - HTML요소를 javascript로 선택하고, 새로운 목록 항목을 동적으로 생성하여 화면에 출력  
이벤트 - 추가 버튼 클릭과 enter 키 입력을 감지하여 할 일이 추가되도록 구현  
배열 사용 - 할 일 목록을 배열로 관리하고, 추가 삭제 반복 출력에 사용  
객체 사용 - 각 할 일을 객체 형태로 저장하여 내용과 완료 상태를 함께 관리  
LocalStorage 사용 - 브라우저 저장소에 데이터를 저장하여 페이지를 새로고침해도 목록이 사라지지 않음  
JSON 변환 - 배열 데이터를 LocalStorage 에 저장하기 위해 문자열로 변환하고, 다시 사용할 때 객체 배열로 변환
